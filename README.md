# Leftik VPN

VPN-клиент для Windows на протоколе **VLESS + Reality (XTLS Vision)**. Работает по той же схеме, что и Amnezia VPN, но код, дизайн и название свои:

1. Вводите **IP, логин и пароль** от своего VPS (Ubuntu / Debian / CentOS).
2. Leftik заходит на сервер по SSH, ставит Xray и генерирует ключи Reality.
3. Клиент подключается в режиме **TUN**, то есть через VPN идёт весь трафик Windows.

Можно добавить и готовый ключ `vless://` (вкладка «По ключу»), и поделиться ключом своего сервера («Серверы → ⋯ → Поделиться ключом»).

## Настройки

**Kill switch.** Пока VPN не подключён, исходящий интернет полностью заблокирован. Работает через брандмауэр Windows (`netsh`): исходящий трафик по умолчанию запрещён. Разрешены:
- ядро Leftik и само приложение;
- адреса туннеля и DHCP;
- IP всех сохранённых VPN-серверов, чтобы туннель поднимался всегда;
- локальная сеть (по желанию);
- **исключения**: программы по полному пути к .exe, сайты и IP. Домены переводятся в IP при сохранении и при запуске Leftik. Если среди исключений есть домены, открывается DNS (порт 53).

Блокировка держится, даже если Leftik закрыт или упал. При выключении kill switch брандмауэр возвращается в исходное состояние из `C:\ProgramData\LeftikVPN\restore-firewall.cmd`. Тот же файл запускает деинсталлятор. Если что-то пошло не так, запустите этот файл от имени администратора.

**Раздельное туннелирование.** Два независимых списка: приложения (`chrome.exe`) и сайты (`youtube.com` с поддоменами, IP или подсеть). У каждого три режима: «Выкл», «Только эти», «Все, кроме этих». Правила такие:
1. Исключения («все, кроме») важнее включений.
2. Если где-то включено «только эти», через VPN идёт всё, что подходит хотя бы под один такой список, а остальное идёт напрямую.

Трафик «напрямую» отправляет само ядро, поэтому раздельное туннелирование работает и вместе с kill switch.

## Запуск

```bash
npm install
```

`npm install` сам скачает ядро [sing-box](https://github.com/SagerNet/sing-box) 1.14.3 в `core/`. Если Electron не скачался (npm 12 блокирует install-скрипты), он докачается при первом `npm start`.

```bash
npm start
```

TUN требует прав администратора. Если приложение запущено без них, оно покажет кнопку «Перезапустить» и перезапустится от имени администратора.

## Сборка установщика

```bash
npm run dist
```

Готовый установщик появится в `dist/`. Он всегда запускается от имени администратора.

## Проверка

```bash
npm run check
```

Проверяет разбор и сборку ключей, экранирование скрипта сервера и прогоняет сгенерированные конфиги через `sing-box check`.

## Как устроено

| Файл | Что делает |
|---|---|
| `src/main/installer.js` | SSH (ssh2): заливает bash-скрипт, ставит Xray, пишет конфиг VLESS + Reality, открывает порт в ufw/firewalld |
| `src/main/singbox.js` | Собирает конфиг sing-box (TUN → VLESS, DNS через туннель, локальные сети напрямую), запускает ядро, отдаёт скорость через Clash API |
| `src/main/vless.js` | Разбор и сборка ссылок `vless://` (tcp / ws / grpc / httpupgrade, reality / tls / none) |
| `src/main/store.js` | Список серверов в `%APPDATA%\leftik-vpn\leftik.json`. Пароль SSH **не сохраняется** |
| `src/renderer/` | Интерфейс |

Если на сервере уже была установка Leftik, при повторной установке используются старые ключи, так что выданные раньше ключи продолжают работать.
