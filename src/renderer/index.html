Серверы

Серверов пока нет.

Добавьте свой сервер по IP, логину и паролю — Leftik сам установит на него VLESS + Reality.

Новый сервер

Нужен VPS с Linux (Ubuntu / Debian / CentOS). Leftik подключится по SSH и сначала проверит сервер: если VLESS Reality там уже есть (от Leftik на другом устройстве или от Amnezia), он просто возьмёт готовый ключ. Иначе установит Xray. Пароль нигде не сохраняется.

Дополнительно

Переустановить заново, даже если VLESS на сервере уже есть (нужно, чтобы сменить порт или маскировку)


      


      

        
Вставьте ключ vless:// — например, тот, которым с вами поделились.

        
        
      

      

    


    
    

      
Настройки


      

        

          

            Kill switch
            
Без подключённого VPN интернет полностью блокируется — никакого трафика мимо туннеля. Действует, даже если Leftik закрыт.

          

          
        

        

          
Разрешить локальную сеть (принтеры, роутер, другие ПК дома)

          
        

        

          

            Исключения: программы
            
Эти программы выходят в интернет и без VPN. Когда VPN включён, они идут через него как обычно.

          

          

            
            
            
          

          
          

        

        

          

            Исключения: сайты и IP
            
Доступны и без VPN. Домены переводятся в IP при сохранении и при запуске Leftik. Если в списке есть домены, разрешается DNS.
